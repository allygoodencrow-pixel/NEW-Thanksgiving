## Non-negotiable behaviors
1. Guest count changes propagate to every quantity that depends on attendance.
2. Homemade dishes generate ingredient and prep requirements.
3. Purchased dishes generate prepared-food purchase requirements instead.
4. Confirmed guest-provided dishes stop generating host shopping/prep requirements.
5. Planned-but-unconfirmed guest contributions remain in host requirements.
6. Removing a dish removes only dependencies generated by that dish.
7. UI must never be the source of calculation truth.
8. Old HTML/CSS/images/navigation must not be restored as the new design.

## Testing rule
Each recovered rule gets a domain regression test before it is wired into the interface.
